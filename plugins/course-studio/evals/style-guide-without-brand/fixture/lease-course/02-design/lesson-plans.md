# Lesson Plans

## Module 1: Lease Anatomy

Learners identify the parts of a commercial lease. Segment "Parts of a lease": a walkthrough of the sections in the order they appear (premises, term, rent, use, defaults). Segment "Opening icebreaker": learners introduce themselves.

## Module 2: Rent Structures

Learners compare gross, net and percentage rent, then apply the abstraction template to rent clauses. Segment "Rent comparison": side-by-side costs of each structure for the same space.

## Module 3: Abstraction Practice

Learners abstract a sample lease using the template.
